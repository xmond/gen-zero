核心架构解析：为什么不能直接把数学无损向量灌给预训练 LLM？（流形对齐与三大落地机制）

1. 流形失配风险（Manifold Mismatch）：开源预训练底座（如 Qwen-0.6B/0.8B）是在常规自然语言词表上预训练的，其 28 层 Transformer 绝未见过人工纯数学构造的 Simplex ETF 或 Cauchy RS 向量。如果直接强行灌入第一层，会导致注意力权重错乱与表征坍缩，绝不可行。
2. 三大工程落地解耦机制：

  • 机制一 · 伴随侧流保真（Sidecar Companion Manifold，生产主推）：借鉴 gen2-cdx1 的“单源真相 vs 派生缓存”分离设计，LLM 骨干依然吃自然语言 Token 序列（运行在最熟悉的预训练流形区），而无损可逆向量 $z$ 作为伴随侧流直通第 2 层 NanoCore 微核与第 4 层 CP-SAT 求解器，兼得语义宽度与符号精度。
  • 机制二 · NanoCore 专科微核直通（Bypass LLM Reflex）：针对 70% 的轻量反射型安全/路由决策，微核本身就是用保熵结构化分布训练微调的，直接以 $z$ 为输入在 0.35ms 内完成前向输出，完全绕开 28 层 LLM 庞大计算。
  • 机制三 · 轻量可逆适配器（Invertible Adapter）：若长程推演确需全量 LLM 参与，则通过单层正交投影 $e = \text{Embedding}(token) + W_{proj} \cdot z$ 经不变性蒸馏对齐后作为残差微扰注入，不破坏底座预训练结构。

✔ 验收红线保证：根据 Issue #69 验收标准，三大决策头 Accuracy Delta 必须严格为 0.00%。若发现任何流形漂移导致决策降级，一票否决！

1.3 隐空间思维链（Latent-Space CoT）三大连续流形动力学路径（0-Token 慢思考规范）

传统思维链依赖离散词表的逐 Token 自回归生成，受制于显存带宽墙与采样不可微缺陷。Gen-Zero 在白化流形 $\mathcal{M}$ 之上，将推理过程重构为连续相空间中的有向动力学演化轨道（详见专门规范文档 ZERO-LATENT-COT-08）：

路径一 · 已落地 常微分神经动力学 (Neural ODE)

数学原理（理论探索形式）：在 64 维超球面 $\mathbb{S}^{63}$ 上，由候选吸引力场与竞争项斥力场联合驱动的连续系统： $$\frac{dz}{dt} = Az(t) + Bx + \sum \alpha_i (z_{c_i} - z) - \sum \beta_j \frac{z_{c_j} - z}{\|z_{c_j} - z\|^2}$$

离散与连续稳定性条件不可混用：代码实际计算并约束的是离散隐状态转移矩阵 $A$（递推 $z_{t+1} = A z_t + \dots$）：用 float64 SVD 求最大奇异值 $\sigma_{\text{raw}}$，再整体缩放 $a_{\text{scale}} = \min(1, \rho_{\max}/\sigma_{\text{raw}})$，保证谱范数 $\sigma_{\max}(A) < 1.0$，维持离散递推的数值稳定（causal/causal_mcts_rnn.py certified_contraction、causal/rnn_set_adapter.py _check_stability；ContinuousCausalReasoningExpert 载入时由 causal/dynamics_calibrator.py certify() 检查 $\rho(A) \le 0.55$ 且 $\sigma_{\max}(A) \le 0.95$）。 而上式连续 ODE $\dot{z} = Az + \dots$ 的线性稳定性需要连续李雅普诺夫条件：存在 $P \succ 0$ 使 $A^T P + P A \prec 0$（即 $A$ 为 Hurwitz 矩阵，全部特征值实部为负）。离散谱条件 $\sigma_{\max}(A) < 1$ 不是连续系统稳定的充分条件（例如 $A = 0.5I$ 满足 $\sigma_{\max} < 1$，但 $\dot{z} = 0.5z$ 发散）。当前代码未检查连续 Hurwitz 条件。

实测特性：单核求解时延 $\approx 200 \sim 500\ \mu\text{s}$，已在 ContinuousCausalReasoningExpert 落地并全套单测通关。落地形式是离散递推 step()，不是上式的 RK4 连续积分。

路径二 · 规划中 隐式循环回传 (Latent Recurrence)

数学原理：借鉴 Coconut / Quiet-STaR 范式，在 896 维隐藏层直接将上一轮输出隐状态作为连续虚拟 Token $e_{t+1} = P_{\text{recur}} h_t$ 注入 KV 缓存，循环 $K$ 步深度逻辑前向： $$h_{t+1} = \text{Trunk}(e_{t+1}, \text{past\_kv}), \quad h_K \to \text{Proj}_{\mathcal{M}}(h_K)$$

实测勘误（2026-09-23）：纯 CPU INT8 带 KV 缓存的单 token 步实测 p50 275 ms，min 266 ms，不是早期写的 15~30 ms。根因：Int8WeightOnlyLinear.forward 每步反量化整块权重，成本与 token 数无关。$K$ 步按 $K \times 275$ ms 线性外推，外推值不作结论（详见 ZERO-UNFREEZE-10 §2）。

路径三 · 理论验证 流形条件流匹配 (Flow Matching)

数学原理：将思考过程定义为流形上从问题初态 $p_0$ 沿测地线滑向确证结论 $p_1$ 的连续概率流，由切空间速度场网络驱动最优传输： $$z_{k+1} = \text{Proj}_{\mathbb{S}^{63}}(z_k + \Delta t \cdot v_\theta(z_k, t_k, c))$$

实测特性：流线高度直线化（Straightened Flow），推断仅需 2~4 步欧拉积分，单核极速时延 ≤ 100\ \mu\text{s}$。

3. 连续最优传输 (Wasserstein) 路由与四正交切空间

离散 Top-k 路由在领域相变边界上存在不连续跳变与震荡问题。Phase 2.1 & 2.2 引入基于 Bures-Wasserstein 测地线距离 的连续动力学路由网关，并配备四组拓扑正交切空间专家池：

Bures-Wasserstein 测地线连续度量

在协方差高斯流形空间，两分布 \(\mathcal{N}_0(\mu_0, \Sigma_0)\) 与 \(\mathcal{N}_k(\mu_k, \Sigma_k)\) 的测地线距离为： 

\(\mathcal{W}_2^2 = \|\mu_0 - \mu_k\|^2 + \operatorname{Tr}\left(\Sigma_0 + \Sigma_k - 2(\Sigma_0^{1/2}\Sigma_k\Sigma_0^{1/2})^{1/2}\right)\)

连续 Softmax 温度加权融合：\(\lambda_k = \frac{\exp(-\mathcal{W}_2 / \tau)}{\sum_j \exp(-\mathcal{W}_2 / \tau)}\)，实现 Lipschitz 连续跨领域平滑过渡。

四正交切空间专家池 (Tangent Pool)

  • 语法切空间 (\(M_{\text{syntax}}\))：处理代码 AST 语法骨架与标点转移
  • 逻辑切空间 (\(M_{\text{logic}}\))：处理因果推演、布尔判定与演绎关系
  • 数值切空间 (\(M_{\text{numeric}}\))：处理算术连续量与高精度数量绑定
  • 意图切空间 (\(M_{\text{intent}}\))：对齐多轮交互目标、意图引导与安全防护

严格代数正交性保证：\(U_i^T U_j = 0 \; (\forall i \neq j)\)，且每个切空间内均独立配备收缩李雅普诺夫矩阵 (\(\rho(A_k) < 1.0\))。

4. 微动力学稀疏 MoE 与 220M 算术壁垒突破

早期规划曾提出将 463M 模型的活跃参数压至 220M 级。经严格数学核算，151K 词表对应 Embedding 即占 155.3M 参数，24 层全注意力占 100.7M 参数，两者保底物理底线为 256.0M 参数。直接声称 220M 属于算术层面的虚假承诺。

科学突破方案：低秩嵌入因式分解 (Factorized Embedding Parameterization)
将词表矩阵解构为 \(V \times E_d\) 与 \(E_d \times d\) 两级映射（选取 \(E_d = 128\)）：
$$\text{Embedding 参数} = 151,643 \times 128 + 128 \times 1,024 = 19,410,304 + 131,072 \approx \mathbf{19.5\text{M}}$$ 单项参数立减 135.8M！结合后 8 层 8 专家 Top-1 稀疏 MoE，将单 Token 活跃参数量真正压入 220M 级（≤ 230M），同时使全模型物理存储稳降至 600MB~700MB，完美守住 1.0GB 硬预算！

5. Phase 2.4 GEPA 闭环对抗自进化飞轮

目标形态的端侧 Zero 模型需要不依赖全量重新训练的自修复能力。GEPA 闭环按三阶段流水线设计，目标是在线连续演化（当前没有线上生产流量接入）：

6. 双通道无损可逆输入向量编码与 LodGraph 结晶容器

继承并强化 RFC-069 原生数学体系：针对端侧推理中的离散输入，采用双通道无损编码体系：

通道 A：Simplex ETF 几何紧框架

构建等角紧框架（Equiangular Tight Frame），将离散 Token 映射至均值归一化的超球面上。对于任意两个基底向量 \(i \neq j\)，严格满足内积 \(v_i^T v_j = -1/(K-1)\)，实现最大化几何角间隔与零距离模糊。

通道 B：Cauchy RS 纠错算子

基于有限域上的柯西生成矩阵（Cauchy Reed-Solomon），将输入特征编码为带校验冗余的数字符号。在擦除数不超过校验冗余的设计范围内（设计值 30% 丢包）可确定性还原输入符号。这是编码层的纠删能力，不能阻止模型本身的幻觉或推理错误。

LodGraph-V1 紧致权重结晶容器 (crates/gen2-crystallizer)

通过 crystallize-zero 编译器 CLI，将 Zero 模型的 safetensors 权重、因果转移 CSR 图、辛 Koopman 动态矩阵与 H-ETF 紧框架字典无损结晶为 150MB 单一二进制镜像，支持 64B 对齐与零拷贝 mmap 纳秒级极速装载。

为什么 Laya (ModernBERT) 无法胜任真实复杂决策？

1. 单步贪婪映射的“地平线死穴”：Laya 本质是单步映射函数 \(f: \mathcal{S} \to \Delta(\mathcal{A})\)。在具有不可逆转移的马尔可夫决策中，单步贪婪选择看起来距离目标更近（曼哈顿距离缩短），但在 3~5 步后必定陷入死锁死胡同。在 30 组欺骗性死胡同实测中，Laya 存活率为 0.0%。
2. 缺乏动态规划算力分配：Laya 对简单反射任务和复杂死锁博弈均消耗固定的 33ms GPU 深度前向算力，无法根据状态熵自适应调用 MCTS 或 A*。
3. 无法离线因果闭环自进化：权重静态冻结，在遭遇反事实对抗扰动或分布外样本时无法在线秩-1 修复与动态重新正交化。

Gen-Zero (Zero) 双系统架构的破局之道

1. System 1 与 System 2 动态连续调度：常规低熵决策直接命中 0.02ms 规则反射缓存；复杂边缘状态自动激活 64 维流形动力学推演与 MCTS 规划，死胡同存活率达成 100.0% 满分破局。
2. 严守单核 CPU 与 1.0GB 物理常驻红线：Zero-Compact-220M 实测单核 CPU 单线程延迟 468.98 ms，BF16 物理大小仅 693.8 MB，推理不依赖 GPU；693.8 MB 的体量超出微控制器的内存，目标部署形态是端侧网关与工控机级 CPU 设备。
3. 李雅普诺夫收缩与 GEPA 在线自进化飞轮：以谱半径 \(\rho(A)=0.9800 < 1.0\) 确保动力学收敛，并通过后台 Daemon 实时监控相变，实现无损正交增量更新。
