1. Current Architecture Overview: Unified Autonomous Model Zero and Its Elastic Lineage

The Gen-Zero architecture consolidates scattered experimental names into one unified model, Zero. The production target is to deploy only a single autonomous model, Zero. Inference depends on no GPU and no external cloud API. It stays resident on one pure-CPU thread on an embedded or low-power server and emits deterministic decisions. This is a design target that is not yet realized in any live production environment. The current open-source release is an open core and experimental prototype. The measured single-core CPU latency of Zero-Compact-220M is 468.98 ms (see Section 8). It is not millisecond-class.

Core architecture analysis: why can we not feed mathematically lossless vectors straight into a pretrained LLM? (manifold alignment and three landing mechanisms)

1. Manifold mismatch risk (Manifold Mismatch): Open-source pretrained bases (such as Qwen-0.6B/0.8B) are pretrained on a regular natural-language vocabulary. Their 28-layer Transformer has never seen artificial, purely mathematical Simplex ETF or Cauchy RS vectors. Forcing them into the first layer would scramble attention weights and collapse the representation. This is not feasible.
2. Three engineering decoupling mechanisms:

  • Mechanism 1 · Sidecar fidelity (Sidecar Companion Manifold, main production recommendation): Borrowing the "single source of truth vs derived cache" separation of gen2-cdx1, the LLM backbone still consumes natural-language token sequences (running in the pretrained manifold region it knows best). The lossless reversible vector $z$ goes as a sidecar stream straight to the Layer 2 NanoCore micro-cores and the Layer 4 CP-SAT solver. This gives both semantic breadth and symbolic precision.
  • Mechanism 2 · NanoCore specialist micro-core bypass (Bypass LLM Reflex): For the 70% of lightweight reflex-type safety/routing decisions, the micro-core itself is fine-tuned on entropy-preserving structured distributions. It takes $z$ directly as input and finishes the forward pass in 0.35ms, bypassing the heavy 28-layer LLM compute entirely.
  • Mechanism 3 · Lightweight invertible adapter (Invertible Adapter): If long-range rollout truly needs the full LLM, a single-layer orthogonal projection $e = \text{Embedding}(token) + W_{proj} \cdot z$ is aligned through invariance distillation and injected as a residual perturbation. This does not damage the pretrained structure of the base.

✔ Acceptance red-line guarantee: Under the Issue #69 acceptance criteria, the Accuracy Delta of the three decision heads must be exactly 0.00%. If any manifold drift degrades a decision, it is vetoed outright.

1.3 Latent-Space CoT: Three Continuous Manifold-Dynamics Paths (0-Token Slow-Thinking Spec)

Traditional chain-of-thought relies on token-by-token autoregressive generation over a discrete vocabulary. It is limited by the memory-bandwidth wall and by non-differentiable sampling. On the whitened manifold $\mathcal{M}$, Gen-Zero reframes reasoning as a directed dynamical evolution trajectory in a continuous phase space (see the dedicated spec ZERO-LATENT-COT-08):

Path 1 · Implemented Neural ordinary differential equations (Neural ODE)

Mathematical principle (theoretical exploration form): On the 64-D hypersphere $\mathbb{S}^{63}$, a continuous system driven jointly by a candidate attraction field and a competitor repulsion field: $$\frac{dz}{dt} = Az(t) + Bx + \sum \alpha_i (z_{c_i} - z) - \sum \beta_j \frac{z_{c_j} - z}{\|z_{c_j} - z\|^2}$$

Do not mix discrete and continuous stability conditions: The code actually computes and constrains the discrete latent-state transition matrix $A$ (recurrence $z_{t+1} = A z_t + \dots$). It takes the largest singular value $\sigma_{\text{raw}}$ with a float64 SVD, then rescales the whole matrix by $a_{\text{scale}} = \min(1, \rho_{\max}/\sigma_{\text{raw}})$. This guarantees the spectral norm $\sigma_{\max}(A) < 1.0$ and keeps the discrete recurrence numerically stable (causal/causal_mcts_rnn.py certified_contraction, causal/rnn_set_adapter.py _check_stability. When ContinuousCausalReasoningExpert loads, causal/dynamics_calibrator.py certify() checks $\rho(A) \le 0.55$ and $\sigma_{\max}(A) \le 0.95$). The linear stability of the continuous ODE $\dot{z} = Az + \dots$ above needs a continuous Lyapunov condition: there exists $P \succ 0$ such that $A^T P + P A \prec 0$ (that is, $A$ is a Hurwitz matrix and all eigenvalues have negative real part). The discrete spectral condition $\sigma_{\max}(A) < 1$ is not a sufficient condition for stability of the continuous system (for example, $A = 0.5I$ satisfies $\sigma_{\max} < 1$, but $\dot{z} = 0.5z$ diverges). The current code does not check the continuous Hurwitz condition.

Measured properties: Single-core solve latency is $\approx 200 \sim 500\ \mu\text{s}$. It is implemented in ContinuousCausalReasoningExpert and the full unit-test suite passes. The implemented form is the discrete recurrence step(), not the RK4 continuous integration of the formula above.

Path 2 · Planned Latent Recurrence

Mathematical principle: Following the Coconut / Quiet-STaR paradigm, the 896-D hidden layer feeds the previous round's output hidden state back as a continuous virtual token $e_{t+1} = P_{\text{recur}} h_t$ into the KV cache, looping a deep logical forward pass for $K$ steps: $$h_{t+1} = \text{Trunk}(e_{t+1}, \text{past\_kv}), \quad h_K \to \text{Proj}_{\mathcal{M}}(h_K)$$

Measured erratum (2026-09-23): A single-token step on pure-CPU INT8 with a KV cache measured p50 275 ms, min 266 ms, not the 15 to 30 ms written earlier. Root cause: Int8WeightOnlyLinear.forward dequantizes the whole weight block at every step, and the cost does not depend on token count. $K$ steps extrapolate linearly to $K \times 275$ ms. The extrapolated value is not a conclusion (see ZERO-UNFREEZE-10 §2).

Path 3 · Theoretically verified Manifold conditional flow matching (Flow Matching)

Mathematical principle: The thinking process is defined as a continuous probability flow on the manifold, sliding along a geodesic from the problem's initial state $p_0$ to the confirmed conclusion $p_1$, with optimal transport driven by a tangent-space velocity-field network: $$z_{k+1} = \text{Proj}_{\mathbb{S}^{63}}(z_k + \Delta t \cdot v_\theta(z_k, t_k, c))$$

Measured properties: Streamlines are highly straightened (Straightened Flow). Inference needs only 2 to 4 Euler integration steps. Single-core latency is ≤ 100\ \mu\text{s}$.

3. Continuous Optimal-Transport (Wasserstein) Routing and Four Orthogonal Tangent Subspaces

Discrete top-k routing has discontinuous jumps and oscillation at domain phase-transition boundaries. Phase 2.1 & 2.2 introduce a continuous dynamical routing gateway based on the Bures-Wasserstein geodesic distance, with four topologically orthogonal tangent-subspace expert pools:

Bures-Wasserstein geodesic continuous metric

On the covariance Gaussian manifold, the geodesic distance between two distributions \(\mathcal{N}_0(\mu_0, \Sigma_0)\) and \(\mathcal{N}_k(\mu_k, \Sigma_k)\) is: 

\(\mathcal{W}_2^2 = \|\mu_0 - \mu_k\|^2 + \operatorname{Tr}\left(\Sigma_0 + \Sigma_k - 2(\Sigma_0^{1/2}\Sigma_k\Sigma_0^{1/2})^{1/2}\right)\)

Continuous softmax temperature-weighted fusion: \(\lambda_k = \frac{\exp(-\mathcal{W}_2 / \tau)}{\sum_j \exp(-\mathcal{W}_2 / \tau)}\), giving a Lipschitz-continuous smooth transition across domains.

Four orthogonal tangent-subspace expert pools (Tangent Pool)

  • Syntax tangent space (\(M_{\text{syntax}}\)): handles the code AST syntax skeleton and punctuation transitions
  • Logic tangent space (\(M_{\text{logic}}\)): handles causal rollout, Boolean judgment, and deductive relations
  • Numeric tangent space (\(M_{\text{numeric}}\)): handles continuous arithmetic quantities and high-precision numeric binding
  • Intent tangent space (\(M_{\text{intent}}\)): aligns multi-turn interaction goals, intent guidance, and safety protection

Strict algebraic orthogonality guarantee: \(U_i^T U_j = 0 \; (\forall i \neq j)\), and every tangent space has its own contraction Lyapunov matrix (\(\rho(A_k) < 1.0\)).

An early plan proposed compressing the active parameters of the 463M model to the 220M class. A strict arithmetic audit shows the embedding for a 151K vocabulary alone takes 155.3M parameters and the 24 full-attention layers take 100.7M parameters. Together they set a physical floor of 256.0M parameters. Claiming 220M directly would be a false commitment at the arithmetic level.

Scientific breakthrough: low-rank embedding factorization (Factorized Embedding Parameterization)
The vocabulary matrix is split into a two-stage mapping, \(V \times E_d\) and \(E_d \times d\) (choose \(E_d = 128\)):
$$\text{Embedding parameters} = 151,643 \times 128 + 128 \times 1,024 = 19,410,304 + 131,072 \approx \mathbf{19.5\text{M}}$$ This one item drops by 135.8M parameters. Combined with the sparse top-1 MoE with 8 experts in the last 8 layers, the per-token active parameter count truly falls into the 220M class (≤ 230M). Total physical storage also falls steadily to 600MB to 700MB, which holds the 1.0GB hard budget.

5. Phase 2.4 GEPA Closed-Loop Adversarial Self-Evolution Flywheel

A target-form edge Zero model needs self-repair that does not depend on full retraining. The GEPA closed loop is designed as a three-stage pipeline. Its goal is continuous online evolution (no live production traffic is connected today):

1. Boundary-case scanning

BoundaryTraceScanner is designed to monitor inference traces. When the confidence margin is \(\text{margin} \le 0.20\) or the Lyapunov residual spikes, it flags the case as a critical adversarial sample and saves it in isolation.

2. Riemannian geodesic perturbation synthesis

CounterfactualAdversarialSynthesizer synthesizes counterfactual perturbations with a strict upper bound (\(\|\delta\| \le 0.05\)) along the normal direction of the current manifold gradient. It tests the basin stability of the critical decision attractor.

3. Incremental contraction-matrix patching

IncrementalManifoldCodebookPatcher runs rank-1 projection updates and dynamically keeps \(\rho(A) < 1.0\) through the spectral scaling theorem. A built-in streaming SVD re-orthogonalization mechanism removes the cumulative basis degradation caused by thousands of updates.

6. Dual-Channel Lossless Reversible Input-Vector Encoding and the LodGraph Crystallization Container

Inheriting and strengthening the native RFC-069 mathematical system: for discrete inputs in edge inference, a dual-channel lossless encoding system is used:

Channel A: Simplex ETF geometric tight frame

Builds an Equiangular Tight Frame that maps discrete tokens onto a mean-normalized hypersphere. For any two basis vectors \(i \neq j\), the inner product strictly satisfies \(v_i^T v_j = -1/(K-1)\). This maximizes the geometric angular margin and removes distance ambiguity.

Channel B: Cauchy RS error-correction operator

Based on the Cauchy generator matrix over a finite field (Cauchy Reed-Solomon), it encodes input features into digital symbols with parity redundancy. Within the designed range where the number of erasures does not exceed the parity redundancy (design value: 30% packet loss), the input symbols can be restored deterministically. This is the erasure-correction ability of the encoding layer. It cannot stop hallucination or reasoning errors in the model itself.

LodGraph-V1 compact weight crystallization container (crates/gen2-crystallizer)

The crystallize-zero compiler CLI losslessly crystallizes the Zero model's safetensors weights, causal-transition CSR graph, symplectic Koopman dynamics matrix, and H-ETF tight-frame dictionary into a single 150MB binary image. It supports 64B alignment and zero-copy mmap loading at nanosecond-level speed.

Why can Laya (ModernBERT) not handle real complex decisions?

1. The "horizon blind spot" of single-step greedy mapping: Laya is essentially a single-step mapping function \(f: \mathcal{S} \to \Delta(\mathcal{A})\). In a Markov decision process with irreversible transitions, a single-step greedy choice looks closer to the goal (shorter Manhattan distance), but after 3 to 5 steps it always lands in a deadlock dead end. In the 30 deceptive dead-end trials, Laya's survival rate was 0.0%.
2. No dynamic allocation of planning compute: Laya spends the same fixed 33ms of deep GPU forward compute on simple reflex tasks and on complex deadlock games. It cannot call MCTS or A* adaptively based on state entropy.
3. No offline causal closed-loop self-evolution: its weights are frozen. Under counterfactual adversarial perturbation or out-of-distribution samples, it cannot do online rank-1 repair or dynamic re-orthogonalization.

How the Gen-Zero (Zero) dual-system architecture breaks through

1. Input candidates carry no semantics In the old training pool, the candidates of ARC / MMLU-Pro were only single letters A..J, so candidate hidden states carried no option content. The 1GB shackle is lifted, and industrial memory budgets of 2GB to 4GB+ are supported.
3. Coconut latency erratum Document 08 once stated a single step costs +12 ms. Measured on pure-CPU INT8 with a KV cache, a single-token step takes p50 275 ms, min 266 ms.
