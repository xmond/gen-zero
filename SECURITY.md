# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [security@gen-zero.ai](mailto:security@gen-zero.ai). Do not open a public issue or include exploit details in a public pull request before a coordinated disclosure. If email delivery fails, use GitHub's private vulnerability reporting feature for this repository if it is available. If neither channel is available, do not publish sensitive details; contact the maintainers through a public issue containing only a request for a private reporting channel.

Include the affected version or commit, impacted component, reproduction steps or a minimal proof of concept, expected and observed behavior, potential impact, and a way to contact you. Remove credentials, personal data, and other sensitive material from the report.

Maintainers will review the report, seek clarification where needed, assess impact, prepare and verify a fix, and coordinate disclosure with the reporter. Response and remediation times depend on impact and maintainer availability; no fixed deadline is promised. Please allow time for a fix before public disclosure. Avoid accessing data that is not yours or disrupting services while investigating.

Security reports are handled separately from community conduct reports; see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the latter.
